# Lviv Polytechnic server catalog

A Ukrainian-language community server directory hosted on GitHub Pages. The site uses semantic HTML, compiled Tailwind CSS, and small native JavaScript modules. There is no application framework or production JavaScript dependency.

## Local development

Use Node.js 22 or newer:

```sh
npm ci
npm run build
python -m http.server 8000
```

Open http://localhost:8000. Serve the directory over HTTP because `index.js` imports a local module.

- Edit `index.html` for content, links, availability, and Tailwind utilities.
- Edit `styles/tailwind.css` for theme colors and base accessibility styles.
- Run `npm run watch:css` while changing classes, or `npm run build:css` for a minified stylesheet.
- Edit `index.js` for wallpaper rotation, logo animation, and dropdown interactions.

`index.css` is generated by Tailwind. Do not edit it directly. Commit it with your HTML changes so GitHub Pages can serve the site without a build step or a Tailwind CDN script.

## Wallpapers

Keep original PNG/JPEG artwork in `everydayimg/`, then run `npm run build:images`. The script creates WebP copies (up to 1920 × 1080, preserving aspect ratio) in `images/wallpapers/` and updates `wallpapers.js`. Commit both generated outputs. If you remove an original image, remove its generated WebP copy too. If you rename or remove `aboutthat.png`, update the initial image and preload paths in `index.html`.

The first wallpaper displays without JavaScript. With JavaScript enabled, wallpapers rotate every seven seconds after the next image has decoded. Only the next image is preloaded. Rotation pauses in hidden tabs and is disabled when reduced motion is requested. The animated logo loads on hover and also respects reduced motion.

## Server information

Server descriptions and availability are maintained manually in `index.html`. The Minecraft card is a static article; there are no status API URLs, API requests, polling timers, player counts, or player-list panels. Visitors can check current availability in Discord. BlueMap remains a normal external link.

## GitHub Pages

Commit `index.html`, `index.js`, `index.css`, `wallpapers.js`, and the referenced image assets. The generated CSS and images are included in the repository, so the existing GitHub Pages static publishing setup does not need to change. To change the generated assets, run `npm ci && npm run build` and commit the results.

This project was made by a human and AI. Feel free to use or modify any part of this code.

## Cloudflare Workers

`wrangler.jsonc` explicitly configures this project as a static-assets-only Worker named `elon-tuskoff-github-io`. The browser's `index.js` is an asset, not a Worker entry point. Wrangler runs `npm run build` automatically, which also assembles the public site in `dist/`. Only browser files are copied; source artwork, build scripts, dependencies, and repository metadata are excluded.

```sh
npm run deploy:check  # Build and validate the deployment without publishing
npm run deploy       # Publish using your Cloudflare account
```

For the connected Cloudflare Workers Builds project, use `npx wrangler deploy` as the deploy command. The dashboard build command can be left empty because Wrangler's custom build command handles it. If the dashboard already runs `npm run build`, it is safe but duplicates the build. Keep the existing production branch selection; merging the PR is separate from pushing its review branch. The generated `dist/` and local Wrangler state are ignored by Git.
